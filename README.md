# 键锋 KEYFORGE — 编程打字练习

一个 **CRT 荧光绿终端**风格的编程打字练习网站——
黑底磷光绿字、扫描线、暗角、辉光脉冲、开机爆闪动画，让练打字像在老式终端机上敲代码。

## 快速开始

无需安装任何依赖，直接用浏览器打开 `index.html` 即可：

- 双击 `index.html`；或
- 命令行启动本地服务器（任选其一）：
  ```bash
  npx serve .
  # 或
  python -m http.server 8000
  ```
  然后访问 `http://localhost:8000`。

## 功能

- **代码打字练习**：内置 32 段代码（JavaScript / Python / Java / C / Go / HTML / CSS / SQL / 其他），
  包含冒泡、插入、选择、归并、快速等排序算法，二分查找、BFS/DFS 等查找搜索算法，以及链表、栈等数据结构
- **实时统计**：准确率、速度 WPM、击键 CPM、用时，进度条与错误计数
- **指法提示**：屏幕键盘每个键上有手指颜色圆点；下一个要按的键会辉光脉冲；
  需要 Shift 时两个 Shift 键同步发光；底部实时提示「该用哪根手指」
- **错误处理**：按错显示红色（抖动 + 低音提示），必须退格修正
- **任务报告**：完成后弹出 CRT 风格报告，评级 S/A/B/C/D，记录每篇历史最佳（localStorage）
- **自定义练习**：粘贴自己的代码/文本练习
- **按键音效**：可开关（WebAudio，无需素材文件）
- **纯前端**：无构建、无依赖、无网络请求，所有数据仅存本地

## 操作说明

| 操作 | 效果 |
| --- | --- |
| 直接输入 | 与高亮字符匹配则前进，否则记错并显示红色 |
| Backspace | 先删除错误字符，再删除正确字符 |
| Enter / 空格（完成后） | 再来一次 |
| Esc | 关闭报告 / 帮助面板 |
| 分类标签 + 下拉框 | 切换练习片段；「随机一篇」随机抽题 |

## 设计特色

- **CRT 荧光终端风**：黑底磷光绿字、扫描线、暗角、辉光脉冲、开机爆闪动画
- **指法可视化**：键位手指分色圆点 + 下一键辉光脉冲 + 实时文字提示，Shift 联动高亮
- **游戏化反馈**：按键音效、错误抖动、完成评级（S/A/B/C/D）、每篇历史最佳与新纪录提示
- **内容自由**：32 段内置代码（含经典排序 / 查找算法）+ 自定义粘贴，分类筛选、随机抽题
- **零依赖**：纯 HTML/CSS/JS，无构建、无网络请求，数据仅存本地

## 说明

- 数据（音效开关、最近练习、历史最佳）存于浏览器 localStorage，不会上传。
- 键盘指法为视觉引导，浏览器无法检测实际手指，正确率仍以输入内容为准。
